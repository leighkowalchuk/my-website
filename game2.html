This is a project that I worked on throughout most of this summer. I wanted to try out a new engine so I decided to try making a 2D game in Godot. The goal behind making this game was to learn and understand important 2D game mechanics like player states, tilesets and tilemaps, UI elements, NPCS and naviagation regions, collectables and inventory systems, day and night cycles, save data and much more. I;m still actively working on this game to continue to expand my knowledge on 2D games.
The first thing I started working on was setting up the files and learning the basics of Godot and GDScript. I found the software to be pretty intuative after watching a few Youtube tutorials. As opposed to the 3D game I am working on, I used premade assets for this game so I could get straight into coding. Later I will replace these with my own tilesets.
In it's current state, I have created an envionnment with trees, flowers and rocks and enterable houses with proper collisions. I have player than can use tools to get materials and plant seeds. The plants grow with the day and night cycle after being watered. I also added cow and chicken NPCS that move around in their pens. I have a basic inventory system working and the player is able to save their progress. The next things that I want to implement are dialog and character interaction, building levels and adding in my own tilesets that I will make in Aesprite.
Once I had implemented a a good amount of features, I made some changes that broke a lot of my game. This was beyond frustrating because I simply could not narrow down where the issue was. Unfortunately, all of my files were saved locally and since I wasn't using any type of version control, I couldn't revert back to an earlier state. I eventually was able to fix my issue and I immediately pushed all my files to a repo. After this mishap, I learned the importance of using tools like Git to keep track of file versions, and its safe to say that I won't make that mistake again.
